# Preserved third-party notices

These files contain upstream license and copyright notices; they are not covered
by the LearnLoop copyright notice in place of their original terms.

- `frontend-runtime-notices.txt`: notice files from 158 installed, non-development,
  non-optional frontend package entries in the committed lockfile. The two remark-math
  monorepo packages without packaged license files use the upstream monorepo license:
  https://github.com/remarkjs/remark-math/blob/main/license .
- `python-dependency-notices.txt`: available notice files and declared metadata from
  the 58 pinned packages in the local Python verification environment.
- `katex-font-notices.txt`: original copyright/license/RFN strings from 20 KaTeX 0.19.0
  TTF files. Their WOFF/WOFF2 forms originate from the same bundled fonts.
- `OFL-1.1.txt`: font-license terms from https://openfontlicense.org/documents/OFL.txt ;
  the applicable font copyright and Reserved Font Names are in the companion notices.

Refresh notices when changing dependencies. Retain upstream notices in installed
packages and build outputs. Metadata inventories are not substitutes for license texts.
