# 演示与验收路线

本演示使用原创 SQL 教材与虚构学习者。计划、知识点、Wiki 和活动记录都是人工预置内容，不是模型生成结果。

运行 `docker compose -f docker-compose.demo.yml up -d --build`，打开 http://localhost:8088 ，使用页面给出的演示账号登录。

1. 首页：查看示例课程与虚构学习记录。
2. 课程 → 计划：查看三天学习安排及待复习卡片。
3. 开始学习：查看 SQL 示例与主动回忆问题。
4. Wiki：查看材料整理后的页面及来源。
5. 图谱：查看三个概念的关联。
6. 开始复习：翻看待复习问题；提交评分会提示只读限制。
7. 管理 → 成本：空调用记录不代表真实使用免费；真实实例未定价调用显示未知。

桌面与375px截图位于 `images/`。`demo-walkthrough.webm` 为本地预置演示的实际浏览器录屏，带讲解字幕、无配音；不包含真实用户或密钥，也不用于证明 AI 生成质量。

要体验真实生成，请使用默认 Compose 的独立实例，配置自己的模型，将 `examples/sql-basics.md` 上传到新建知识课程，等待入库后与规划师沟通并生成计划。记录所选服务/模型、开始与完成时间、调用次数和 token。费用有未定价部分时标注未知，最终账单以服务商为准。
